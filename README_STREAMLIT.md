# CampusX Book Recommender — Streamlit version

## Run locally

1. Create and activate a virtual environment (recommended).
2. Install dependencies:

   ```bash
   pip install -r requirements.txt
   ```

3. Start the app:

   ```bash
   streamlit run app.py
   ```

Keep `popular.pkl`, `pt.pkl`, `books.pkl`, and `similarity_scores.pkl` in the same folder as `app.py`.

The original HTML templates and Flask Procfile were removed from this converted copy because the UI now uses Streamlit components. The original notebook is retained for reference.
